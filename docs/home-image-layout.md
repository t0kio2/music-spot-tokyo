# ホーム画像の表示調整

## 目的と背景

microCMS から取得したホーム本文の画像が、共通の `.prose figure` の最大幅 640px によって狭く表示される。また、縦長画像は画面内に収まる高さの上限がない。ホームに限って本文幅を活用しつつ、画像全体を無理なく確認できる表示にする。

## 影響範囲

- `src/pages/index.astro`: ホーム本文内の画像に限定したレイアウト指定
- `test/home-image-layout.test.mjs`: ホーム固有の画像表示ルールの回帰テスト

データモデルと API の変更はない。

## 実装方針

1. ホーム本文内の `figure` だけ共通の 640px 上限を解除する。
2. 画像は元のアスペクト比を維持し、横幅は本文領域、高さはビューポート内を上限にする。
3. microCMS の `set:html` で挿入される要素にも適用できるよう、Astro の `:global()` を子要素に使用する。

## 検証

- ホーム固有の `figure` と `img` のルールが存在することを自動テストで確認する。
- `astro build` で Astro テンプレートと CSS が正常にコンパイルできることを確認する。

## トレードオフ

縦長画像は高さを優先して縮小されるため、本文領域の横幅いっぱいにはならない。画像を切り抜かず、全体を表示することを優先する。
