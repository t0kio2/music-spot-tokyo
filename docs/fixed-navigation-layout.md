# 固定ナビゲーションと本文スクロール

## 目的と背景

ページ全体のスクロールに伴って左ナビゲーションと上部 SNS ヘッダーが画面外へ移動している。ナビゲーションとヘッダーを常時表示し、本文領域だけをスクロール可能にする。

## 影響範囲

- `src/layouts/Layout.astro`: グリッドの高さ、スクロール領域、フッター位置
- `src/components/Header.astro`: サイドバーのビューポート高指定
- `test/fixed-navigation-layout.test.mjs`: レイアウト構造の回帰テスト

データモデルと API の変更はない。

## 実装方針

1. `.site` を `100svh` に固定し、共通の上部ヘッダー高を定義する。
2. 上部ヘッダーと左サイドバーを `position: fixed` でビューポートへ固定する。
3. `.content` を固定ヘッダーの下、サイドバーの右側へ `position: fixed` で配置し、この要素だけに縦スクロールを設定する。
4. フッターを `.content` の末尾へ置き、本文と一緒にスクロールできるようにする。
5. モバイルでは本文とヘッダーの左端を画面端へ切り替える。
6. サイドバーの高さを `100svh` に揃える。

## 検証

- `.site` が画面高に固定され、外側のスクロールを発生させないことをテストする。
- ヘッダーとサイドバーが明示的な固定配置であることをテストする。
- `.content` のみが縦スクロールを持つことをテストする。
- フッターが本文スクロール領域内にあることをテストする。
- 全テストを実行する。

## トレードオフ

ブラウザのページスクロールではなく `<main>` がスクロールコンテナになる。`svh` によりモバイルブラウザの表示領域変化でコンテンツが隠れにくい構成を優先する。
