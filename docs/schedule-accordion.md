# スケジュールのアコーディオン表示

## 目的と背景

スケジュール一覧を「よくある質問」と同じ操作感のアコーディオンにする。閉じた状態ではイベントの `title` だけを表示し、番号や日付などの補助表示は付けない。

## 影響範囲

- `src/pages/schedule.astro`: イベント一覧のマークアップとスタイル
- `test/schedule-accordion.test.mjs`: 表示構造の回帰テスト

microCMS のデータモデルと API 呼び出しは変更しない。

## 実装方針

1. イベントの `article` をネイティブ HTML の `details` と `summary` に置き換える。
2. `summary` には `ev.title` だけを置く。
3. 展開領域には既存の `ev.content` をリッチテキストとして表示する。
4. FAQ と同様に先頭のイベントを初期表示し、開閉記号とカード表現を揃える。
5. 今後の予定がない場合のメッセージは維持する。
6. `::details-content` の高さを 0 から自動高さへ補間し、上から下へ展開・収縮させる。
7. `prefers-reduced-motion: reduce` の場合はアニメーションを無効にする。

## 検証

- `details`、`summary`、先頭要素の `open` が存在することをテストする。
- summary にタイトルだけが入り、日付表示と番号表示がないことをテストする。
- 展開・収縮のトランジションと低モーション設定をテストする。
- 全テストと Astro ビルドを実行する。

## トレードオフ

イベント日はアコーディオン見出しに表示しない。必要な日付情報は microCMS の本文側で提供する前提とする。アニメーション非対応ブラウザでも、ネイティブの `details` として開閉できる。
