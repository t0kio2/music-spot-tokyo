# 概要
タイトルは「MuSTの読みもの」
 カテゴリーは４つ
①「MuSTについて」
MuSTを立ち上げた背景や音楽を通じて作りたい居場所、運営で大切にしている考え方などを紹介します。 
②「楽器・演奏の楽しみ方」
器の練習方法や演奏のコツ、バンド活動に役立つ知識などを紹介します。
③「音楽仲間・居場所づくり」
社会人になってからの音楽仲間の作り方や、一人でも参加しやすいサークルの選び方などを紹介します。 
④「活動報告」
ライブやセッション、練習会の様子、参加者の声など、MuSTの実際の活動をお届けします。
