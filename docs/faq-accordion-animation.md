# FAQ アコーディオンのアニメーション

## 目的と背景

FAQ の開閉を、スケジュール画面と同じく上から下へ滑らかに展開・収縮する動きに揃える。

## 影響範囲

- `src/pages/faq.astro`: FAQ 本文の開閉スタイル
- `test/faq-accordion-animation.test.mjs`: アニメーション指定の回帰テスト

データモデル、API、HTML 構造は変更しない。

## 実装方針

1. `::details-content` の高さを 0 から自動高さへ 0.3 秒で補間する。
2. 高さの変化に短いフェードを組み合わせる。
3. `prefers-reduced-motion: reduce` ではトランジションを無効にする。
4. Q 番号、質問、回答、先頭項目の初期展開は維持する。

## 検証

- 展開時と収縮時の高さ指定をテストする。
- 低モーション設定が存在することをテストする。
- 全テストを実行する。

## トレードオフ

アニメーション非対応ブラウザでは即時開閉になるが、ネイティブの `details` としての操作性は維持される。
