# ファビコン画像の生成

## 目的と背景

`public/icon.webp` のネオンサインをサイトのファビコンとして利用する。元画像は横長のため、円形ロゴを中心に正方形へ切り出し、小サイズで利用できる静的アセットを用意する。

## 影響範囲

- `public/favicon-source.png`: 元画像から切り出した正方形の高解像度素材
- `public/favicon-32.png`: ブラウザタブ用画像
- `public/apple-touch-icon.png`: Apple 端末用画像
- `public/favicon.ico`: 従来ブラウザ向け画像
- `src/layouts/Layout.astro`: ファビコン参照
- `test/favicon.test.mjs`: 参照と画像寸法の検証

API とデータモデルの変更はない。

## 実装方針

1. AI 編集版は文字の正確性を満たさないため採用しない。
2. 元画像の中央 768×768 を切り出し、ロゴと文字を改変せず正方形化する。
3. 32×32、180×180、ICO の各形式へ縮小する。
4. HTML から PNG、ICO、Apple Touch Icon を参照する。

## 検証

- ファビコンの参照先が存在することをテストする。
- 各画像のピクセル寸法をテストする。
- 全テストを実行する。

## トレードオフ

小さいファビコンでは円周上の文字まですべて読むことは難しいが、ネオンの円形意匠と配色による識別性を優先する。
