サークル全般について

  1. 1参加者間でトラブルが発生した際は当事者同士での解決をお願いします。
  2. 2練習会、ライブ本番における貴重品や機材等の管理は各自でお願いします。
  3. 3ライブ・練習会の様子を撮影し、各種SNSやYouTubeにアップさせていただきますのでご容赦ください。
  4. 4応募いただいた内容に虚偽があった場合や、他の参加者を不快にさせる言動が多い方、運営上支障があると判断した方は、参加をお断りすることがございます。
  5. 5曲のエントリー後に出演を辞退される場合は、以下のキャンセル料金が発生しますのでご注意ください。
¥・ライブ本番の日から2か月以内：出演料の50%
・ライブ本番の日から1か月以内：出演料の100%
※100円未満切り上げ
  1. 6招待されたLINEグループでは、返信、投稿をしないでください。連絡事項が追いづらくなってしまいます。ご質問等がある場合は、運営者の個人LINEにご連絡お願いします。
♙

練習会について （3月・9月の定期ライブのみ）

  1. 1練習会には極力参加くださるようお願いします。欠席された場合は次回参加の際、制限事項がございます。
  2. 2第1回、第2回ともに同じ時間割となります。各自、スケジュールの調整をお願いします。なお、時間の指定はお受けできません。
  3. 3スタジオ代は参加者の割り勘となります。練習会の14日前以降に金額をアナウンスします。（1,000円〜1,500円程度）
  4. 4やむを得ず欠席する場合は練習会の14日前までにご連絡をお願いいたします。それ以降のご連絡であった場合、スタジオ代をいただく形となります。
  5. 5ご自身の演奏曲が始まる10分前までには到着しているようお願いします。
  6. 61曲当たりの練習時間が概念よりも30分程度と短いため、すぐにスタジオに入れるよう演奏機材の事前準備をお願いします。

勧誘行為の禁止

以下の行為を禁止します。

  1. 1他サークル、他イベントへの勧誘行為
  2. 2主催者に無断でサークル内のメンバーとバンドを結成すること
  3. 3退会したメンバーからの勧誘を受け、他サークルや他イベントへ参加すること。

each other.

ライブについて

  1. 1ライブ直前や当日のドタキャンはしないようお願いします。
  2. 2本番直前で欠員が出てしまった場合、欠員パート無しでの演奏か、出演代行を依頼するか、曲の中止となる場合がございますのでご了承ください。
  3. 3ボーカルの方について、スマホや楽譜を見ながら歌うのはご遠慮ください。（代行出演の方は除く。）
